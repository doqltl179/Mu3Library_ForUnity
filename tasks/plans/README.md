# Task Plans

This folder holds the execution plan for active non-trivial work. It is not an archive, and only this README is tracked in Git.

**The rules that govern these files are owned by the [Task Record Policy](../../docs/ai-agents/plans/task-record-policy.md)** — file naming, the `tasks/todo.md` index split, completion deletion, and the approval-free closeout. Follow that page rather than a copy kept here.

What is specific to this folder:

- Prefer at most one active plan file here during normal work.
- Use one file per bounded serial task. Graph work keeps the whole request in one plan through the [graph plan contract](../../docs/ai-agents/workflow/graph-engineering.md); never create one plan per node.
- Start from the standard shape in [plan-template.md](../../docs/ai-agents/plans/plan-template.md).
