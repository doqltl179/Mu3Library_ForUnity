# Mu3 Library (Base)

Core runtime package of **Mu3Library For Unity**: the `CoreBase`/DI container, MVP UI system, audio, scene loading, Addressables/Localization/InputSystem managers, WebRequest, Observable, player-hosted multiplayer sessions, and the shared editor tooling.

- Package name: `com.github.doqltl179.mu3library.base`
- Optional integrations (enabled by define symbols when the package is present): UniTask, Addressables, Localization, Input System, Steamworks.NET (separate `Mu3Library.Multiplayer.Steam` assembly). [Optional Packages](https://github.com/doqltl179/Mu3Library_ForUnity#-optional-packages) in the repository README gives their define symbols and platform limits.
- Local notifications for Android and iOS are in the separate Notifications package, `com.github.doqltl179.mu3library.notifications` ([README](../notifications/README.md)), from the next release.
