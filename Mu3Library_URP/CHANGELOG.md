## [0.4.0] - 2026-10-31

- See `urp/0.4.0` in the repository root `CHANGELOG.md`. Highlights: Unity 6000.3 becomes the lowest supported Editor; the four screen effects work in a player build through the package's `ScreenEffectShaders.asset`; and the unused `MU3LIBRARY_URP_SUPPORT` define symbol and the script-less Editor assembly definitions are removed.

- See `urp/0.3.0` in the repository root `CHANGELOG.md`. Highlights: `ScreenEffectManager` implements `IDisposable`, and `UnregisterEffectAll<TEffect>()` matches effect types again.
