# Mu3 Library URP

URP add-on package of **Mu3Library For Unity**: screen effects (grayscale, gaussian blur, depth outline, shake) driven through `ScreenEffectManager`, and camera stack helpers.

- Package name: `com.github.doqltl179.mu3library.urp`
- Requires the Universal Render Pipeline.
